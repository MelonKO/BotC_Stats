# BotC Uploader — Project Context

## 📋 Обзор проекта

**BotC Uploader** — это Python-скрипт для загрузки CSV-файлов с данными игр в базу данных **Blood on the Clocktower** через REST API. Скрипт автоматизирует процесс импорта: парсит CSV, группирует данные по партиям и отправляет каждую партию на `POST /api/import` endpoint.

Проект является частью экосистемы BotC и работает с API, описанным в `../docker-botc/api/`.

### Технологический стек

| Компонент | Версия/Значение |
|-----------|-----------------|
| **Python** | 3.10+ |
| **requests** | >=2.31.0 (HTTP-клиент) |
| **python-dotenv** | >=1.0.0 (загрузка переменных окружения) |
| **API Endpoint** | `POST https://<host>/api/import` |

## 🏗️ Архитектура

### Процесс импорта

```
CSV файл → Парсинг → Группировка по партиям → HTTP POST /api/import → БД
```

1. **Парсинг CSV** — чтение файла, извлечение данных
2. **Группировка** — объединение строк по уникальной комбинации `(game_date, scenario_name, storyteller_name, color_win)`
3. **HTTP-запрос** — отправка JSON на API endpoint с заголовком `X-API-Key`
4. **Обработка на сервере** — API валидирует роли, вставляет в staging, вызывает `process_games_import()`
5. **Результат** — возврат статуса, ID партии, количество созданных игроков

### Основные функции (`uploader.py`)

| Функция | Назначение |
|---------|------------|
| `load_config()` | Загрузка параметров API из `.env` |
| `validate_csv_file()` | Проверка существования и расширения файла |
| `parse_csv()` | Парсинг CSV и группировка по партиям |
| `send_import()` | Отправка одной партии на `POST /api/import` |
| `main()` | Точка входа: orchestrator всего процесса |

### Виртуальное окружение Python

Проект использует **виртуальное окружение Python** для изоляции зависимостей. Все пакеты устанавливаются локально в директорию `venv/`, которая игнорируется Git (через `.gitignore`).

**Работа с виртуальным окружением:**

```bash
# Создание виртуального окружения (первый раз)
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/macOS)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Деактивация
deactivate
```

```bash
# Активировать виртуальное окружение
venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt
```

### 2. Конфигурация

```bash

copy .env.example .env

# Отредактировать .env и указать реальные параметры API
```

### 3. Получение API-ключа

API-ключ создаётся на сервере с помощью скрипта:

```bash
cd ../docker-botc
bash scripts/create-api-key.sh create "Ваше Имя"
```

### 4. Запуск загрузки

```bash
python uploader.py <путь_к_csv_файлу>
```

**Пример:**
```bash
python uploader.py ../test_sample.csv
```

### Формат CSV

CSV-файл должен содержать заголовок и следующие колонки:

| Колонка | Описание |
|---------|----------|
| `game_date` | Дата игры (YYYY-MM-DD) |
| `scenario_name` | Название сценария |
| `storyteller_name` | Имя рассказчика |
| `color_win` | Победившая команда (синий/красный) |
| `player_name` | Имя игрока |
| `role_start_name` | Начальная роль |
| `role_end_name` | Конечная роль |
| `color_end` | Команда игрока в конце (синий/красный) |
| `is_alive` | Выжил ли игрок (true/false) |

> **Важно:** Один CSV-файл может содержать несколько партий. Скрипт автоматически группирует строки по уникальной комбинации `(game_date, scenario_name, storyteller_name, color_win)` и отправляет каждую партию отдельным запросом.

## 🔐 Безопасность

- **`.env` файл игнорируется Git** (через `.gitignore`) — не коммитьте API-ключи
- **`venv/` игнорируется Git** — виртуальное окружение локально для каждого разработчика
- **API-ключи** хранятся как SHA-256 хеши на сервере
- **SSL_VERIFY=false** рекомендуется только для self-signed сертификатов (локальная разработка)
- Для продакшена используйте HTTPS с валидным сертификатом и `SSL_VERIFY=true`

## 🛠️ Устранение неполадок

| Проблема | Решение |
|----------|---------|
| `.env` не найден | Скопируйте `.env.example` в `.env` и настройте параметры |
| Ошибка подключения | Проверьте, что контейнер запущен (`docker-compose ps`) |
| `Invalid API key` | Убедитесь, что API-ключ в `.env` совпадает с созданным через скрипт |
| `API key has been revoked` | Ключ отозван — создайте новый |
| SSL ошибка | Установите `SSL_VERIFY=false` в `.env` |
| Отсутствуют роли | Добавьте роли в таблицу `roles` перед импортом |
| Модуль не найден | Активируйте виртуальное окружение: `venv\Scripts\activate` |
| Зависимости не установлены | Запустите `pip install -r requirements.txt` |

## 📝 Связь с родительским проектом

Проект `botc-uploader` работает в связке с:

- **`../docker-botc/api/`** — FastAPI REST API для импорта
- **`../docker-botc/`** — Docker-контейнер с PostgreSQL и API
- **`../BotC_Schema.sql`** — схема базы данных PostgreSQL
- **`../README.md`** — общая документация экосистемы BotC

Перед использованием uploader убедитесь, что:
1. Docker-контейнер запущен (`cd ../docker-botc && docker-compose up -d`)
2. API-ключ создан (`bash scripts/create-api-key.sh create "Имя"`)
3. Схема БД инициализирована (автоматически при первом запуске)
